# Shadow Blind Review 试标协议

对应票据：`ENG-005`。目标是验证新标注者能否只靠页面指南完成盲测与复核，不评估模型质量。

## 准备

负责人分别创建普通标注和复核 demo；访问文件必须保持 `0600`，仅把对应角色 token 单独发给
参与者。服务只监听 `127.0.0.1`，试标不连接 GB10，也不加载 Mage 模型。

```bash
PYTHONPATH=src .venv/bin/python scripts/create_annotation_demo.py /tmp/shadow-pilot-rate
PYTHONPATH=src .venv/bin/python scripts/create_annotation_demo.py \
  /tmp/shadow-pilot-review --review-ready
```

## 15 分钟流程

1. 邀请至少 2 名未参与实现的人；不口头解释操作，只告知地址和 token。
2. 每人先完成 3 道普通题，再由至少 1 人完成复核题。
3. 记录首次有效提交耗时、误操作、是否发现快捷键、是否理解平局与跳过、刷新后能否继续。
4. 结束后只问三个问题：哪里需要猜？哪里最慢？哪段文案会让你改变原本判断？
5. 将反馈追加到本文件末尾的运行记录，不写入模型身份或参与者真实姓名。

## 通过门槛

- 所有人无需实现者介入即可完成首次提交；无已确认答案丢失。
- 所有人能正确解释“平局”和“跳过”的差异，复核者理解自己看不到原投票。
- 单题中位操作时间不因界面操作超过 30 秒；无模型、文件名或磁盘路径泄露。
- 任何阻断性问题必须修复并重新试标，才能关闭 `ENG-005`。
