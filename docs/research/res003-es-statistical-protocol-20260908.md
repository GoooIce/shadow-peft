## 1. 重复层级与独立性单位

从粗到细只承认以下重复层级；每一下层都嵌套在上层内，跨层不得当作独立重复相加：

| 层级 | 定义 | 统计角色 |
|---|---|---|
| 噪声组（noise group） | 预注册 noise-family seed，组内共享镜像方向、组间独立 | 复现单位；固定顺序族 |
| episode / 批 | 8 个互不重叠 prompt 的一个 episode（N=80 候选） | 配对效应的**独立重复单位**（符号翻转在这层做） |
| prompt | 冻结池样本 ID | 区间估计的**簇**（bootstrap 整簇重采样） |
| 生成 seed | 同 prompt 的派生 seed | 簇内观测；**整簇附着 prompt**，永不单独成样本 |
| 评审员 / 盲测重复 | 同一配对的多次判断 | 一致性诊断；不增加独立 prompt 数 |

精确重放、重放审计和 20% 质控重复项都共享原簇；`k` 永远数 prompt/episode，不数图。
32M 个基因组坐标、276 个 cosine 对均不是独立样本（§4、§6）。

## 2. 主终点与机制分解

- **主比较（唯一确认终点）**：最终候选 E 对 raw healed master H 在**未见 prompt**（封存
  `human_test` / `auto_test` 池）上的配对 Reward 增益；Reward 为 ENG-003 冻结的等权
  z 合成（0.5·z_HPS + 0.5·z_CLIP，z 用冻结 BF16 均值/std 标定）。
- **机制分解（预定次级，只描述不确认）**：E − P（ES 增量）与 P − H（起点投影/latent
  往返增量），P 为 effective center；同 prompt 同 seed 三臂配对。
- **单列报告，不进主终点**：HPS/CLIP 分轴、教师轨迹损失、GenEval/OCR 诊断、人工偏好
  （EXP-011 另有 §8 的冻结判据）。

## 4. 区间与检验算法

1. **prompt 簇 bootstrap 区间**（主报告）：以 prompt 为簇整簇重采样、簇内 seed 全携带，
   统计量 = 簇均值的无权重均值；百分比区间，索引与 `image_eval.paired_bootstrap_mean_difference`
   完全一致。EXP-013 的「固定 10,000 次分层配对重采样」中，重采样次数、seed 与 prompt
   整簇口径由本协议冻结；其 GenEval 六任务分层由既有 `geneval.paired_clustered_bootstrap`
   （ENG-003 实现）承载，本票不重复实现。
2. **episode 级符号翻转检验**：k 个 episode 的配对增量，在 episode 层随机赋 ±1；
   统计量 = 翻转后均值。零假设成立条件：episode 内配对增量在镜像/翻转下对称、
   episode 可交换。k=8 共 256 个模式可精确枚举。**不使用把 28/276 对当独立样本的
   naive 区间**——它在 k=24、d=40 的合成零假设下实测 5% 名义拒绝率 4.9%、k=8 时 7.1%，
   且该口径在任何共享结构下都无保证（review F02）。
3. **cosine 的 episode 翻转零假设**：整条 episode 梯度变号时其参与的全部 cosine 对同时
   变号（(i,j) 对乘 s_i·s_j），据此构造均值 pairwise cosine 的零假设分布；
   naive sd / flip sd 比值随结果一并报告。
4. **失败与 shaping**：所有模拟的判定层与真实管线同构（episode 级配对增量、
   失败 episode 显式失效），zscore shaping 的退化情形（全同分）按 `NoRewardSignalError`
   语义显式失败，不静默补零。

## 5. 联合选择/确认门：误报率与功效（k=8/16，每格 10,000 次模拟）

episode 级配对增量取 Normal(μ, σ_ep)，μ 以 σ_ep 为单位：

| μ/σ_ep | k=8 通过率 | k=16 通过率 |
|---:|---:|---:|
| 0（纯零假设） | **0.146** | **0.039** |
| 0.25 | 0.316 | 0.162 |
| 0.50 | 0.537 | 0.422 |
| 0.75 | 0.741 | 0.717 |
| 1.00 | 0.882 | 0.903 |
| 1.50 | 0.988 | 0.997 |
| 2.00 | 0.999 | 1.000 |

解读（全部写入结果解释约束）：

- 零假设下 k=8 联合门仍有 **14.6%** 通过率（与 review 解析示例 37/256 ≈ 14.45% 同量级）：
  **胜场门不是显著性证明**。选择阶段的通过因此只用于挑 α/候选，确认阶段另加
  α_conf=0.01 的符号翻转检验（k=8 精确最小 p = 1/256 ≈ 0.0039 < 0.01，可分辨）。
- 注册规则本身是 ≥6/8；k=16 列按同比例外推为 12/16，是**设计校准**，不是重新注册的规则。
- 若确认阶段要在 0.9 功效下检出，需要真实效应 ≥ 1.0σ_ep（k=8/16 都成立）；
  0.5σ_ep 的弱效应在本预算下约一半概率漏检 → 只能写「证据不足」。

## 6. 一致性检查点规则的含义边界（k=8/16/24，d=40，每格 10,000 次）

episode 梯度方向建模为 √ρ·真方向 + √(1−ρ)·独立噪声（E[cosine]=ρ）：

### 6.1 各检查点孤立通过率

| 真实 ρ | k=8 通过率 | k=16 通过率 | k=24 通过率 |
|---:|---:|---:|---:|
| 0（纯噪声） | 0.002 | 0.000 | 0.000 |
| 0.05 | 0.072 | 0.011 | 0.002 |
| 0.10（=阈值） | **0.433** | **0.425** | **0.408** |
| 0.15 | 0.838 | 0.957 | 0.987 |

### 6.2 整套顺序双检查点规则（24 批预算，(8,0.10,0.70)→(16,0.10,0.70)，首个失败即停）

| 真实 ρ | 停在第 1 检查点 | 停在第 2 检查点 | 存活（两关全过） |
|---:|---:|---:|---:|
| 0（纯噪声） | 0.999 | 0.001 | **0.000** |
| 0.05 | 0.925 | 0.069 | **0.006** |
| 0.08 | 0.755 | 0.148 | 0.097 |
| 0.10（=阈值） | 0.580 | 0.146 | **0.274** |
| 0.15 | 0.163 | 0.016 | 0.821 |
| 0.20 | 0.013 | 0.000 | 0.987 |

- 检查点对纯噪声几乎永不误放行（整套规则零假设存活率 0.000）：它是保守的**方向一致性门**。
- 但作为整套顺序规则，它实际是一道 **≈0.15 的效应量门**：真实平均 cosine 恰在阈值
  0.10 时，campaign 有 **72.6%** 概率被停（0.580 死在第一关、0.146 死在第二关，
  与 EXP-009 实际在 k=8 被停的情形一致）；ρ=0.05 时 99.4% 被停。**触发停止的支撑
  措辞是「未检测到跨批方向一致性（真实 ρ 大概率 ≲0.15）」，不是「无梯度/无有用
  增益」**——cosine 阈值与 δ 不在同一尺度上（详见 §10 映射）。

## 8. 人工偏好功效（EXP-011：30 prompt × 2 seed × 3 评审 = 每 prompt 6 判断）

判定：每 prompt 净偏好 = 偏好 E 比例 − 偏好 H 比例（平局计 0），prompt 簇 bootstrap
95% 区间 + δ_pref = **0.10**（10 个百分点净偏好）三措辞判定；重复判断/质控项共享 prompt 簇。

| 场景 | 支持率（可继续） | 误报（q=0.5） |
|---|---:|---:|
| decisive 0.6，q=0.6 | 0.555 | — |
| decisive 0.6，q=0.7 | 0.990 | — |
| decisive 0.8，q=0.6 | 0.684 | — |
| decisive 0.8，q=0.7 | 0.999 | — |
| 任一场景 q=0.5 | — | ≤0.032 |

30 prompt 足以在「六成评审偏好且六至八成可判定」场景下获得 ≥0.55 的支持概率；
若 decisive 率或 q 更低，结论只能落在「证据不足」档。decisive 率（0.6/0.8）与
q=0.5 误报 ≤3.2% 均为合成模型假设，非人工 pilot 实测。

## 9. 多重比较与候选锁定

- **噪声组（EXP-010 三组）**：按冻结 seed 顺序做**固定顺序族**检验（各 α 不折扣），
  首个未通过即停止后续组；该族总误报 ≤ α。弱组不得补抽 seed、不得删除。
- **低维臂（EXP-014）**：Holm 校正，结果标记探索性；不与主线终点混报。
- **最终候选**：只按 selection 规则（含 §5 联合门 + α_selection）从预定 α 集合中固定，
  candidate SHA 在 confirmation 前锁定；确认失败只能终止或重新立项，**不得从确认
  结果里换赢家**。
- 分轴与教师损失为描述性报告，不做确认声明，不做事后主终点切换。

## 10. 判定措辞映射（冻结）

对任一配对效应（含 E−H、E−P、P−H、分轴描述）计算点估计与 §4 区间后：

| 条件 | verdict | 冻结措辞 |
|---|---|---|
| 区间上界 < δ | `practical-gain-excluded` | 「已排除实用增益：区间上界低于冻结的最小有用增益 δ。」 |
| 区间下界 > 0 且点估计 ≥ δ | `gain-supported` | 「可继续：配对效应区间下界高于 0 且点估计达到冻结的最小有用增益 δ。」 |
| 其余 | `insufficient-evidence` | 「证据不足：区间覆盖 0 或未达到冻结的最小有用增益 δ，只能给区间结论。」 |

- 点估计为正但区间覆盖 δ 以下的样本属于 `insufficient-evidence`（detail 记
  `positive_point_estimate=true`），不得写成「无增益」。
- 「已排除实用增益」在点估计为正时同样成立（正但不够有用），detail 单列。

**对 EXP-009 停止门的措辞映射**（不改既有 EXP-009 记录，仅给后续引用的标准说法）：
EXP-009 于 2026-09-08 在 k=8 检查点停止（mean cosine 0.0555 < 0.10，
positive fraction 0.714 ≥ 0.70）。按本协议 §6，其可支撑表述为：
「在检查点尺度上**未检测到跨批方向一致性**（前 8 批 28 对共享 episode 的均值 pairwise
cosine 低于预注册阈值）；该停止**不构成**『无梯度』或『无实用增益』的统计证据」。
后续票据（EXP-010/012/014）引用此结论时必须使用该表述。

## 11. 假设与限制

- 功效/误报表来自**合成模型**（episode 正态噪声、方向 √ρ 分解、评审二项模型），
  用于设计期定标，不替代实测；σ_ep 真值由 EXP-012 首次测量。
- 符号翻转的成立条件是 episode 内配对增量符号对称、episode 可交换；若奖励存在
  与方向符号相关的系统偏置（如非对称惩罚），该条件失效，须在分析记录中声明。
- bootstrap 区间在 k=8/16 的小样本下覆盖偏松、误排除率实测 ≤5.6%（§7），已按
  「记录不回调」处理；若未来改口径，须在 test 前重新冻结（EXP-013 票面同款要求）。
- 本票零 GPU 时；未启动/租用任何实例；未改动 EXP-009、review、既有代码与旧票据。
