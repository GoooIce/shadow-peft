ShadowPEFT × LFM2.5 实验程序总结

2026-08-25 · 程序 v3(LFM2.5 家族 × GB10,自驱动队列)· 四条实验线:①量化恢复 · ②投机解码 · ④异构消融 · ⑤条件化谱系 · 测试床 LFM2.5-{230M,350M,1.2B}-Base/it · 度量轴 despaced wikitext ppl(ctx=512)· 全部数字源自 GB10 runs/ 的 verdict.json

① 量化恢复 通过 地板被击穿

2-bit 受损下 shadow 挽回 99.9%;shadow÷全精度 46x→31x→25x 随规模单调改善。08-26/27 三连战役:单遍结构地板 1524(28.5x)被结构×计算×lr 三轴击穿,再经峰值校准(lr 峰 1.7e-4、r 定格 4、调度负结果)收于 176.4(3.3x,较初锚降 89%);4-bit 档 59.2(1.11x)近无损,compute 精化在 4-bit 为负结果(配方按比特档分化)。三战役终报。

② 投机解码 τ 过 / wall-clock 判负

τ 可调 2.4–4.7;wall-clock 三级证据闭环(链式 1.02x、块式 0.77x、上限 ~1.3x)——统一内存 per-forward 地板结构性封顶,终报。

③ Recirculation 边界 未定(须补 A0)

B1 48 配置网格:conv 源灾难(+27%)、attention 源微弱(−0.4%)均不过 −2% 线;B2 shadow 流可组合零增益——待 A0 论文复现锚定论。

④ 异构消融 H1 成立

跨家族 Llama shadow 仅 +22% 慢;conv 主导臂 +107% 最差——shadow 是通用 attention 追踪器,不绑定宿主架构。

⑤ 条件化谱系 注入不增值

四点定线 1.51 / 2.99 / 3.47 / 5;KV 注入反降 14%——detached 边缘叙事强化:部署无需上行目标特征。

① 量化恢复:损伤与挽回(2-bit 三值 + Lloyd,10M tokens 蒸馏)

全精度 2-bit 量化 量化 + shadow

④ 异构消融:shadow 需要长得像宿主吗?(同 2-bit 基座,参数对齐 ≈35M)

白话:attention 占比越高恢复越好(剂量效应);跨家族 Llama shadow 只落后 22%——镜像论(H2)否决,通用追踪器(H1)成立,shadow 可为任意廉价 attention 架构。意外:纯 conv shadow(3-token 记忆)没崩溃(3825)但仍差 107% 且无法缓存解码,重映射默认值保留。

② 投机解码:detached draft(350M-it → 1.2B-Instruct,k=4)

引擎:链式起草 + 批量验证 + 快照/回滚/重放;无损保证在纯注意力对上严格逐 token 相等(本地),实弹 fp32 3/3 相等;conv 混合的缓存/全量算法差异致稀有近平局翻转(数值现象,非逻辑)。

校准冻结:oracle τ=5 → 成功线 3.0 / 放弃线 2.0。未蒸馏基线 τ=3.22 已过线(同家族天然一致)——v1 蒸馏到 3.47 后饱和(轨迹 3.5–3.6 平台);v2 触发条件未命中。

wall-clock 战役三级证据终审(runs/exp2/{wallclock,v2block_*}):链式 k 全谱扫描(2→8)峰值 1.021x @ k=3——τ 随 k 涨到 4.66 但串行 draft 链占 42%;v2-block 双结构(用户裁决的「一次前向吐 k token」)5M tokens 同源蒸馏后:DSpark 并行头 τ=1.52、DFlash2 精化 τ=2.63,但 68% partial 率使重放占 39%,最优仅 0.765x;上限外推:零成本 draft 2.46x、地板 draft ~1.3x、过线需 τ≥4.5(家族天花板 3.5)。1.4x 在此类硬件上结构性不可达。净收获:bonus 折叠 −19%、RTT 内含口径(vs 无状态云端 2.1x@50ms)、τ×结构光谱(1.52/2.63/4.66/9)与⑤的注入谱系互证。终报见 docs/experiment-wallclock-report.html。

⑤ DFlash2 条件化谱系:特征条件化值多少 τ?(k=4,同一引擎/教师)

判决:KV 注入反降 14%(2.99 vs 3.47),判据落入"注入不值"档——detached 边缘叙事强化(部署无需上行目标特征;与数据中心 DFlash/DSpark 的条件化收益形成边界对照)。机理已锁定:训练时全位置有真实教师特征,推理起草时新 token 零注入——drafter 被训成依赖注入(KD 低至 0.39 却输在 greedy 接受率,"分布匹配 ≠ 自条件一致"的实证);间隙感知训练记为已识别的改进自由度。
