名词卡(白话):ppl(困惑度,猜下一词的"惊讶程度",越低越好,全精度基线=53.5); 2-bit/4-bit 量化(把模型每个数压到 2/4 个比特,体积暴减但能力受损); 影子修补器 shadow(挂在受损模型旁的小型辅助网络,蒸馏训练学会修坏输出); 蒸馏(影子模仿全精度老师的输出分布);lr(学习率,训练步长); 迭代精化(同一修补模块反复套用 r 遍,参数不变计算×r,扩散模型去噪的直觉)。

战役一(floor):旧地板

单遍 shadow 结构 + 默认 lr 下:容量/喂料双轴饱和,地板 1,524–1,552(28.5x),定性为量化噪声主导。

战役二(floor-2):地板被击穿

补上结构×计算×lr 三个被漏掉的轴:迭代精化 + 校准 lr 把 2-bit 压到 265(5.0x)——再降 82%。

战役三(floor-3):峰值校准收官

lr 峰值锁定 1.7e-4(2.4e-4 回升)、r 定格 4(r=6 更差)、调度负结果(cosine 恒定输 4.8%)。组合终点 176.4 = 3.3x——三段式累计较初锚 降 89%。

机制修正

"量化噪声地板"实为"单遍结构 + 欠训练的地板"。compute 精化救灾难(2-bit −30%)、伤轻伤(4-bit 反效果):恢复配方按比特档分化。

⑤ 4-bit 档定局
