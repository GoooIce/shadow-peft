# 质数聚焦 + 原作 faithful 聚合：零迁移在两种聚合约定下复现

日期：2026-09-13｜分支：`codex/wayfinder-minicpm5-qes-faithful`
机器：`goooinext`｜产物：`goooinext:~/minicpm5-w8a8qes/out/{seed*_prime,seed*_primeN50*,faithful_seed*}`

## 结论

**在 240 道全新 hold-out 质数题上，五次独立运行的合格读数全部相同：0.5042 = 121/240 = q0 的基线——一道题的判定都没翻转。** 其中包括把聚合完全对齐到原作（z-score 系数 ±3 截断、无系数和归一、γ=0.9、N=50 对）之后的两枚种子。搜索侧一切健康（每代移动 ~511 坐标、KL 1.085–1.120、跑满 100 代无停机），训练池上的 gold_prob 有真实波动但并不趋势上行，且其波动不产生任何 hold-out 迁移。

¹ N=25 线的 dev 读数（其 gen400 中心）；faithful 线的 dev 是 gen400 中心对 gen300 参照（A 的 gen300 dev = 0.6292）——两线 dev 变化都在 ±1.7 点内，属 dev 噪声（分辨率 ~2 点），无遗忘信号。

三次「旧约定 N=50/80」的尝试在 gen301 以 `no_accept` 停机：`moved=0`、`u_abs_max=0.4615 < 0.5`（半格投影阈值）——原因是我们自加的 `÷2Σ|c| ≈ M+1` 归一随 N 稀释步长（原作没有这一项；它的 1/σ 归一在我们的单位里是恒等）。这正是本次转向原作时要修的，修完后 faithful 线立即恢复移动（511/代）。

## 机制事实（可复用）

1. **原作 faithful 的逐步真相**（一手源码）：`c=clip((d−mean)/std,±3)`（镜像对的奖励差 z-score）、两侧 ±对称、梯度**只按 1/σ 归一**、`u=α·g+decay·e`（decay 默认 0.9）、`round`、残差 clamp ±1.5。我们的实现现以此为可配选项（`--coef-transform zscore --coef-normalize none --gamma 0.9`），聚合变体进中心身份哈希。
2. **α 标定**：faithful（无归一）在 α=0.25 时 u_max≈1.28、移动 511/代——与旧约定 α=12 时 U_max≈0.92、移动 384/代的量级相当；两种约定的「有效步长」被各自标定到同一工作区间后，**结果的零迁移不变**。
3. **零迁移不是拒答伪影**：prime test 上两臂 `na=0.0000`；也不是「搜索不动」（faithful 中位 511/代）；也不是「没信号」（gold_prob 窗口波动 0.2034–0.2181，只是不趋势上行）。

## 判定与措辞（按预注册规则）

- 主张规则要求 test 配对 CI 下界 > 0 且旧 dev 非劣。两种子 test 点估计 = 0.0000（121 对 121，逐题配对差全零）→ **CI 退化于 0，主张不成立**。
- 最强可站住的表述：**「质数判定无法通过该更新族（int8 码格点、每候选 32 处 ±1 步、25–50 对 × 100 代）从训练池迁移到 hold-out 题」**；这是任务—更新族的联合性质，不再能被归因到我们的聚合约定（rank/z-score）、归一化、γ、或种群规模（N=25 与 50 同为零）。
- 与主战役一致：那次的封存池效应 ±0.5 点、种子方差主导；这次的效应**恰为零**且逐题为空——两次都指向「该搜索在此位格上改不了离散判定」。
