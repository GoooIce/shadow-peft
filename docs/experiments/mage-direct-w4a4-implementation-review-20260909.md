## Spec

1. **P1，合法 OCR 锁会被 08 拒绝。** 08 用紧凑 JSON 的 `digest_json` 比较 OCR 配置、计划和报告的公开身份，而 OCR 对象使用自己的确定性序列化。这违反票 08 对真实测量证据的接入要求。修复按类型解码并使用各对象 `.sha256`，归档文件 SHA 与锁的规范化身份单独校验，成本映射也使用真正的配置身份。
2. **P1，真实原生批的身份含义不一致。** 08 曾要求原生报告的 `request_sha256` 等于完整候选请求的 digest，但原生报告记录的是生成样本列表身份。这会阻断票 08 所需的真实三轴原生开发批。修复保留已实测的原生合同，核验实际样本列表与完整请求到报告的绑定，并增加跨模块回归。
